# 头条 AI 前端训练营：AI 创作者辅助生产与分发平台设计

日期：2026-05-22

## 1. 背景与目标

本项目基于《头条AI前端训练营 - AI 创作者辅助生产与分发平台.pdf》设计并实现一个面向内容创作者的 AI 辅助生产与分发平台。

目标不是做孤立功能集合，而是交付一条完整、可演示、可评估的闭环：

1. 创作者登录平台。
2. 上传并管理图片素材。
3. 通过 Prompt、素材、选题、受众、平台和风格生成短图文 / 种草内容。
4. 编辑器自动保存草稿，并支持断网继续编辑与恢复同步。
5. 发布前执行 AI 内容安全审核、质量评分和合规改写。
6. 审核通过后发布内容。
7. 内容进入热点榜、新发布和推荐流。
8. 阅读、热度和反馈回流到榜单排序。
9. 通过规则体系页和效果评估页展示审核规则、质量标准、准确率和排序贡献。

## 2. 范围

### 2.1 必做核心功能

- 用户中心：邮箱密码注册登录、手机号验证码模拟登录、安全退出。
- AI 内容创作：Prompt 管理、素材管理、AI 短图文生成、发布后二次编辑。
- 草稿与版本：每 30 秒云端保存，再次进入自动恢复，断网本地编辑，网络恢复后同步。
- 内容 AI 审核：涉黄、涉赌、涉毒、敏感信息、低俗内容等风险审核；高风险拦截；一键合规改写。
- 内容质量评分：按预定义质量维度给出分数，用于分发排序。
- 内容分发：热点榜、新发布、推荐流、详情页、无限滚动加载。
- 性能优化：榜单和详情页以 LCP <= 2.5s 为目标进行设计和验证。

### 2.2 进阶挑战

- 短图文创意编辑器：使用“素材 + 选题 + 风格 + 受众 + 平台”的结构化生成流程。
- 高精度内容安全识别：规则库 + AI 审核 + 本地测试集评估，目标展示高危识别准确率 90%+。
- 智能排序热点榜单：综合质量分、阅读热度、发布时间衰减、用户反馈和审核健康度排序，并提供排序解释。

### 2.3 非目标

- 不做复杂企业后台权限体系。
- 不做真实短信发送，手机号验证码采用本地模拟。
- 不强依赖真实开放平台 API；热点数据和分发可使用本地模拟。
- 不把数据看板放在主流程之前，避免削弱创作闭环。

## 3. 技术方案

采用 Next.js App Router + TypeScript 单体全栈架构。

### 3.1 技术栈

- 前端：Next.js、React、TypeScript。
- 服务端：Next.js Route Handlers。
- 数据层：Prisma。
- 开发数据库：SQLite。
- 部署数据库建议：PostgreSQL。
- AI 调用：OpenAI SDK 兼容接口，预留火山方舟配置。
- AI 兜底：mock provider。
- 文件上传：开发阶段使用本地 / public 存储；线上部署时使用对象存储，或使用预置演示素材作为无对象存储账号时的降级方案。
- 测试：单元测试、API 测试、端到端测试、审核准确率测试、性能验证。

### 3.2 部署与存储模式

项目按两个运行模式设计，避免本地开发和线上部署的存储假设混淆。

本地演示模式：

- 数据库使用 SQLite。
- 上传文件保存到项目本地目录。
- AI key 缺失时使用 mock provider。
- 适合开发、录屏和本机答辩演示。

线上部署模式：

- 推荐使用 Vercel 部署 Next.js 应用。
- 数据库切换到 PostgreSQL。
- 上传文件不依赖 Vercel 本地文件系统，改用对象存储；如果没有对象存储账号，则线上演示使用预置素材库，保留上传入口但提示“线上演示模式使用预置素材”。
- 公开 URL 或二维码需要用户提供 Vercel / GitHub / 数据库等账号环境后完成部署。
- `docs/deployment.md` 必须说明本地运行、Vercel 部署、数据库迁移、环境变量和对象存储配置。

### 3.3 架构原则

- 单体交付，边界清晰：页面、API、数据模型和 AI 适配层在同一项目内，但通过模块边界隔离。
- 主链路优先：创作、审核、发布、分发、评估必须完整可演示。
- AI 可用但不脆弱：真实 API 优先，失败时自动降级到 mock，不中断演示。
- 安全不放行：审核失败时不能直接发布，必须降级为规则库审核或标记人工复核。
- 可解释：审核、评分和排序都给出原因，便于评分和答辩。

## 4. 模块边界

### 4.1 前端页面

- 登录/注册页
- 创作台
- 素材库
- 内容管理
- 审核与质量页
- 热点 / 新发布 / 推荐榜单页
- 内容详情页
- 规则体系页
- 效果评估页

### 4.2 API 边界

- `/api/auth/*`：邮箱密码注册登录、手机号验证码模拟、退出登录。
- `/api/materials/*`：图片上传、素材列表、素材合规检测。
- `/api/prompts/*`：Prompt 模板增删改查。
- `/api/drafts/*`：草稿保存、恢复、同步。
- `/api/posts/*`：内容发布、二次编辑、详情、列表。
- `/api/moderation/*`：安全审核、合规改写、测试集评估。
- `/api/ranking/*`：热点榜、新发布、推荐流、排序解释。
- `/api/ai/*`：统一 AI 生成、评分、审核适配入口。

### 4.3 数据模型

核心实体：

- `User`：用户账号、邮箱、手机号、密码哈希、创建时间。
- `Material`：素材文件、类型、上传者、合规状态、风险说明、引用次数。
- `PromptTemplate`：Prompt 名称、场景、内容、变量、启用状态。
- `Draft`：草稿内容、本地同步状态、最后保存时间、版本号。
- `Post`：已发布内容、标题、封面、正文、标签、发布状态、发布时间。
- `ModerationResult`：审核结果、风险等级、风险类型、命中规则、建议动作。
- `QualityScore`：原创性、结构、信息密度、表达、互动潜力、平台适配度、总分。
- `RankingMetric`：阅读量、点赞、收藏、反馈分、新鲜度、综合排序分。
- `AuditRule`：规则分类、描述、风险等级、命中模式、处理策略。
- `EvaluationCase`：测试样例、预期风险、实际结果、是否命中。

## 5. 核心业务流程

### 5.1 登录

用户可通过邮箱密码或手机号验证码模拟登录。邮箱密码使用哈希存储；手机号验证码由本地接口生成并在演示环境显示。

### 5.2 素材上传与校验

用户上传图片素材后，服务端记录素材并进行基础校验：

- 文件类型
- 文件大小
- 文件名风险词
- 可选 AI / mock 合规判断

素材状态：

- `safe`：可用于创作和发布。
- `warning`：允许创作，但发布前需重点审核。
- `blocked`：不可用于发布。

### 5.3 AI 短图文生成

创作台输入：

- 选题
- 目标受众
- 平台
- 风格
- Prompt 模板
- 已选素材

AI 输出：

- 标题候选
- 正文段落
- 标签
- 封面建议
- 发布建议

没有真实 API key 或调用失败时，mock provider 返回稳定的高质量示例。

### 5.4 草稿保存与断网同步

编辑器每 30 秒保存到云端草稿接口，同时写入本地缓存。

断网时：

- 编辑器继续可用。
- 状态显示为本地待同步。
- 修改写入本地缓存。

恢复网络后：

- 自动上传本地修改。
- 根据版本号和更新时间判断冲突。
- 冲突时允许用户保留本地版本、使用云端版本或另存为新草稿。

### 5.5 审核、评分与改写

发布前必须审核。

安全审核输出：

- 风险等级
- 风险类型
- 命中规则
- 原因说明
- 建议动作

质量评分维度：

- 原创性
- 结构完整度
- 信息密度
- 表达清晰度
- 互动潜力
- 平台适配度

处理策略：

- 高风险：禁止发布。
- 中风险：提示修改或一键合规改写。
- 低风险：允许发布，但记录风险提示。
- 无风险：直接允许发布。

### 5.6 发布与分发

审核通过后生成 `Post`，进入内容详情页和榜单候选池。

榜单综合分初版：

```text
综合分 = 质量分 * 0.45 + 热度分 * 0.30 + 新鲜度 * 0.15 + 反馈分 * 0.10 - 风险惩罚
```

榜单包括：

- 热点榜
- 新发布
- 推荐流

榜单支持无限滚动，并显示排序解释。

## 7. 错误处理与降级

### 7.1 错误处理

- 登录失败：区分账号不存在、密码错误、验证码错误、会话过期。
- 上传失败：保留用户选择状态，提示失败原因。
- AI 调用失败：自动切换 mock provider。
- 审核失败：降级为规则库审核；仍无法判断则标记人工复核。
- 发布失败：保留草稿和审核结果，允许重试。
- 草稿冲突：保留本地和云端版本，让用户选择。

### 7.2 AI 降级策略

- 内容生成：真实 API 失败 -> mock 短图文。
- 内容审核：真实 API 失败 -> 本地规则库 + mock 风险分类。
- 合规改写：真实 API 失败 -> 模板化改写。
- 质量评分：真实 API 失败 -> 本地评分函数。
- 榜单排序：始终本地可运行。

## 8. 测试与验收

### 8.1 测试类型

- 单元测试：排序分数、质量评分、审核规则、草稿冲突判断。
- API 测试：注册登录、素材上传、草稿保存、审核、发布、榜单分页。
- 端到端测试：注册、上传素材、生成内容、审核、发布、榜单出现、打开详情。
- 审核准确率测试：使用本地测试集计算高危识别准确率。
- 性能测试：榜单页和详情页记录 LCP。

### 8.2 验收标准

- 能完成登录到发布再到榜单展示的完整闭环。
- 已发布内容可二次编辑和重新审核。
- 草稿自动保存间隔为 30 秒。
- 断网编辑可继续，恢复网络后可同步。
- 高风险内容不能发布。
- 可一键生成合规替代内容。
- 质量评分进入榜单排序。
- 榜单支持无限滚动。
- 审核测试集展示 90%+ 高危识别准确率。
- 榜单或详情页具备 LCP <= 2.5s 的实测或说明。
