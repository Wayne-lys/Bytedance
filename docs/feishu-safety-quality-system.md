# 飞书文档草稿：内容安全审核规则库与质量评估体系

## 1. 体系目标

内容安全与质量体系用于保证平台内短图文内容在发布前完成风险识别、自动干预和质量评估。系统要求做到：

- 高危内容不能发布。
- 中风险内容必须改写或复核。
- 安全内容可以发布并进入榜单。
- 质量分参与推荐排序。
- 发布后的下线、撤回、回滚可追踪。

## 2. 风险分类

当前规则库覆盖：

| 风险类型 | 示例边界 | 处理策略 |
| --- | --- | --- |
| 涉黄 | 色情暗示、低俗交易、成人引流 | 高危拦截 |
| 涉赌 | 赌博、下注、稳赚回本、博彩诱导 | 高危拦截 |
| 涉毒 | 毒品、吸毒、违禁药物诱导 | 高危拦截 |
| 敏感信息 | 身份证、银行卡、住址、手机号泄露 | 中高风险拦截或改写 |
| 广告导流 | 私信、进群、扫码、外部联系方式 | 中风险改写 |
| 低俗内容 | 侮辱、恶俗标题、夸张低质表达 | 低中风险提示或改写 |

## 3. 风险等级

| 等级 | 含义 | 发布策略 |
| --- | --- | --- |
| safe | 未发现明显风险 | 允许发布 |
| low | 有轻微表达风险 | 允许发布，但保留提示 |
| medium | 需要改写或复核 | 阻止发布 |
| high | 高危违规 | 直接拦截 |

## 4. 审核链路

1. 创作者编辑或 AI 生成内容。
2. 点击发布时系统自动发起审核。
3. 本地规则库先进行确定性扫描。
4. 如果配置 Ark/OpenAI-compatible API，再进行 AI 语义复核。
5. 系统选择更高风险等级作为最终结果。
6. 通过审核后生成 review token。
7. 发布接口校验 token，确保发布内容与审核内容一致。
8. 审核失败时保留内容并展示失败原因。
9. 用户可点击一键合规改写。
10. 改写后必须重新审核。

## 5. 自动干预

- 高风险：发布失败，展示风险原因和命中规则。
- 中风险：发布失败，建议改写或人工复核。
- 低风险：发布通过，但保留风险提示。
- 合规改写：调用 `/api/moderation/rewrite` 生成替代表达，避免导流、隐私泄露和高危词。

## 6. 发布后治理

内容管理接口 `/api/posts/[id]/status` 支持：

- `offline`：内容下线，不再出现在榜单。
- `withdraw`：创作者或运营撤回内容。
- `rollback`：将治理后的内容恢复为已发布状态。

榜单接口只读取 `published` 内容，因此下线和撤回会立即从热点、新发布和推荐榜单移除。

## 7. 质量评估维度

质量分范围为 0-100，维度如下：

| 维度 | 评估重点 |
| --- | --- |
| 原创性 | 是否避免模板化、洗稿和重复表达 |
| 结构 | 标题、正文、段落和清单是否清楚 |
| 信息密度 | 是否提供足够具体的方法、场景或事实 |
| 表达清晰 | 语言是否准确、自然、易读 |
| 互动潜力 | 是否有适合评论互动的开放问题 |
| 平台适配 | 是否适合头条/信息流短图文分发 |

## 8. 质量分应用

质量分用于：

- 审核页质量展示。
- 内容详情页质量摘要。
- 推荐榜排序公式。
- 平台效果评估报告。

推荐公式：

```text
score = quality * 0.45 + heat * 0.30 + freshness * 0.15 + feedback * 0.10 - riskPenalty
```

## 9. 用户反馈闭环

真实反馈包括：

- 详情页打开次数，计入阅读。
- 点赞数。
- 评论数。

这些信号会刷新反馈分，反馈分进入推荐榜排序。这样平台可以从静态审核和质量分，进一步走向读者真实反馈驱动的分发优化。

## 10. 准确率评估

系统使用 `EvaluationCase` 保存安全样本、中风险样本和高风险样本。评估服务计算：

- 总样本数
- 高危识别准确率
- 误杀数量
- 漏判数量
- 风险分布

目标为高危问题识别准确率不低于 90%。
