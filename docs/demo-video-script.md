# 演示视频脚本

> 建议时长：3-5 分钟。目标是让评委快速看到“创作 -> 审核 -> 发布 -> 分发 -> 反馈回流”的完整闭环。录屏前建议关闭浏览器开发者工具，避免露出环境变量、API key、数据库连接串或控制台错误。

## 录制前检查

- 打开线上地址：https://bytedance-theta.vercel.app
- 使用管理员账号：`admin@example.com` / `Demo123456`
- 确认 Vercel 最新部署状态为 `Ready / Production`
- 如果 Ark key 暂时不可用，为了视频稳定，可以在 Vercel 暂时移除 `AI_API_KEY` / `AI_MODEL` 后重新部署，让演示走本地 mock provider；提交文档中保留“已实现 OpenAI-compatible / Ark 接入，真实 key 可用时自动调用”的说明。
- 准备一个安全选题，例如：`通勤路上的轻量补能`，目标受众：`城市白领`。

## 分镜脚本

### 0:00 - 0:25 项目入口与定位

打开首页，说明：

“这是 AI 创作者辅助生产与分发平台，覆盖短图文创作者从素材管理、Prompt 模板、AI 生成、内容审核、发布管理到榜单分发的完整链路。”

展示：首页工作台、左侧导航、查看榜单入口。

### 0:25 - 0:55 登录与权限

进入登录页或说明当前已登录账号，展示顶部用户身份。

说明：

“系统支持邮箱和手机号验证码登录注册，管理员和创作者拥有不同权限；发布前的审核和内容治理需要审核员或管理员权限。”

### 0:55 - 1:30 素材与 Prompt

进入“素材资产”，展示素材卡片、合规状态、引用次数。

进入“创作台”，展示右侧 Prompt 模板和素材上下文。

说明：

“创作台可以选择素材和 Prompt 模板，素材会作为生成上下文和发布封面来源，Prompt 模板用于控制生成风格。”

### 1:30 - 2:10 AI 生成与草稿保存

在创作台填写：

- 选题：`通勤路上的轻量补能`
- 目标受众：`城市白领`
- 发布平台：`头条`
- 内容风格：`真实、具体、信息密度高`

点击“AI 生成”。

说明：

“AI 生成时其他按钮会锁定，避免并发操作。生成结果包含标题、正文、标签、封面建议和发布建议。系统每 30 秒自动保存草稿，并支持本地恢复和断网继续编辑。”

如页面显示“生成来源：Ark AI”，说明真实接口已调用；如显示“本地 mock / 本地兜底”，说明当前演示环境使用稳定兜底能力。

### 2:10 - 2:55 审核与发布

点击“发布内容”。

说明：

“发布前系统必须先审核。审核采用本地规则 + Ark/OpenAI-compatible AI 双重机制，返回风险等级、命中原因和六维质量分。审核通过后才会创建发布内容；如果内容违规，会保留原稿并提示未通过原因。”

如果演示中选择安全内容，展示发布成功和详情页入口。

### 2:55 - 3:35 内容详情与反馈

进入内容详情页，展示正文、素材图片、标签、质量分、阅读次数。

点击点赞，提交一条评论。

说明：

“内容详情页是真实消费页，每次打开会增加阅读次数；点赞和评论会形成反馈分，参与推荐榜单排序。”

### 3:35 - 4:20 榜单与排序

进入“热点榜单”，切换热点 / 新发布 / 推荐。

说明：

“热点榜按真实阅读次数由高到低排序；新发布按发布时间倒序；推荐榜综合质量分、阅读热度、发布时间新鲜度、用户反馈和风险惩罚进行动态加权。”

点开一条榜单详情，展示排序解释和阅读次数。

### 4:20 - 4:50 模拟抖音分发

回到已发布内容详情页，找到“外部分发 / 抖音图文”面板，点击“同步到抖音图文”。

说明：

“由于真实抖音开放平台需要主体资质、线上域名、OAuth 回调和权限审核，本项目实现了沙盒模拟分发适配层。审核通过并发布的内容可以一键同步到抖音图文模拟平台，系统会持久化外部作品 ID、同步状态和同步时间。”

### 4:50 - 5:00 总结

说明：

“项目完成了登录注册、AI 创作、素材和 Prompt 管理、草稿自动保存、发布前审核、质量评估、内容管理、榜单推荐、反馈回流和模拟外部分发，形成了从生产到治理再到分发的闭环。”

## 注意事项

- 不要在视频中打开 Vercel Environment Variables、`.env`、飞书密钥文档或 Neon 连接串。
- 如果真实 Ark key 失效导致 401，可以说明“真实 provider 已接入，当前资源池 key 不可用，因此演示使用 mock fallback 保证链路稳定”。
- 提交视频链接如果不是强制项，可以在提交文档中写“未提供，线上环境可直接体验完整链路”。
